# A06 — evidenza

- Commit: working tree su `a9899c6`, non committato.
- Comando: `pnpm gate A06`
- Ambiente: Node v22.23.1, Darwin 25.6.0 arm64. Nessuna rete: `fetch` sostituito da un Ollama e un OpenRouter finti (`tests/helpers/model-network.ts`).
- Esito: verde. Il test costruisce l'engine con `modelWiring(env)`, lo stesso cablaggio del processo engine (`protocol/runtime.ts`), non con la fixture.
  - `local_only` con una chiave OpenRouter impostata e un modello cloud di Ollama installato: tutte le chiamate vanno a `127.0.0.1:11434`, nessuna intestazione di autorizzazione, nessun audit `network`; l'OCR usa `glm-ocr` e l'analisi `qwen2.5:7b-instruct-q4_K_M`, mai il modello cloud.
  - Solo modelli cloud installati: analisi `model_unavailable`, zero `/api/chat`, screenshot rifiutato con audit `ocr_failed` / `remote_model`. `OCTO_OLLAMA_URL` su un altro host: nessuna chiamata e nessun lettore OCR.
  - Chiave impostata con `model.configure` (verifica su `/key`): `cloud_after_review` invia al server finto il testo dell'evidenza approvata e non quello non approvato; l'audit `network` elenca solo l'id approvato; la chiave non compare in `audit_events` né in `analysis_runs`.
  - OpenRouter che chiude la connessione alla prima chiamata: un run `error` e un run `accepted`, due audit `network`.
  - Risposta con un id inventato (`e99`): due run `rejected` (primo tentativo e ripresa) con `issues.unknownEvidence = ["e99"]`, motivo `unusable_output`, nessun episodio.
  - 450 frame: tre blocchi (200, 200, 50) che coprono tutte le evidenze; il secondo prompt elenca l'attività `a1` già trovata e il modello la continua; `evidenceSent = evidenceTotal = 450`, `lastRun.partial = false`.
  - `acceptModelOutput` rifiuta evidenze sconosciute, durate oltre la sessione e campi extra.
- Unitari del gate: `runtime` (slot locale e remoto, `OCTO_MODEL=off` lascia il remoto, URL di test solo loopback), `batches`, `remote-slot`, `ollama` (modelli cloud, OCR e vision esclusi), `openrouter`, `policy`, `reply` (id inventati, doppi e domande orfane segnalati; righe di testo che non possono aprire una riga nuova), `cadence`.
- Limiti: il modello vero è B06 (`pnpm test:model:live`) e `pnpm test:ollama`; non entrano in `gate:all` né in CI.
